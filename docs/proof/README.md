# Bằng chứng theo từng phase (Proof)

Đặt bằng chứng kiểm chứng của mỗi phase ở đây (log chạy test, ảnh chụp màn hình, kết quả đo hiệu năng...). Bằng chứng phải **khớp với commit ở tag tương ứng**.

- `phase-1/` — bằng chứng Phase 1
- `phase-2/` — bằng chứng Phase 2
- `phase-3/` — bằng chứng Phase 3
- `phase-4/` — bằng chứng Phase 4

Mỗi thư mục phase nên có một file ghi: lệnh đã chạy, kết quả đạt/không đạt, và ghi chú trung thực cho chỗ chưa đạt.
